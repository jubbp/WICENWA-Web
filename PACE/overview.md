## DRAFT ONLY

This Plan is currently only a DRAFT and has not been accepted or implemented by WICEN WA. It is largely incomplete.



This document describes the communications architecture used by WICENWA during emergency operations.

It does not yet say what WICEN WA can deliver to a supported agency {% include gap.html id="GAP-023" %}, which WA hazards and seasons it prepares for {% include gap.html id="GAP-037" %}, or where in the state it expects to operate {% include gap.html id="GAP-038" %}.

The plan follows the **PACE model**:

Primary  
Alternate  
Contingency  
Emergency  

Each layer assumes the previous layer has failed — **with one exception**: within the Local/Tactical Field Comms domain, the Alternate tier (local digital mesh/messaging — technology not yet chosen {% include gap.html id="GAP-009" %}) is run in parallel with Primary as standard practice, not held in reserve. See the [Domain Summary](./domain-summary) for why this plan is organised into domains rather than one universal ladder, and for that exception in full.
